2. **3D Model Sourcing & GitHub Pages Compliance**:
   - From Observation 2, `model-jantung.glb` (18.14 MB) is on disk, and `model-quill.glb` (90.19 MB) is stored in git blob `7a4f4ed6c35c3ea36715e945571e7864a12abddb`.    - Next.js static export (`output: 'export'`) automatically copies `public/models/*` to `out/models/*` without Webpack JavaScript bundle processing, preventing JS chunk bloat.
   - Both models are $< 100\text{ MB}$, complying with GitHub repository limits, and combined site weight is $\approx 115\text{ MB} \ll 1\text{ GB}$, fully complying with GitHub Pages limits.
   - Restoring the exact Lub-Dub cardiac pulse formula for Heart and levitation/scribe formulas for Quill recovers the authentic animations requested by the user.

## 3. Caveats

1. **Git Object Checkout**: `public/models/model-quill.glb` is currently deleted in the working directory. The implementer must execute `git checkout f894fdf -- public/models/model-quill.glb` (or `git restore public/models/model-quill.glb`) to bring the 90.19 MB binary asset back onto disk before running build/test checks.
2. **MeshoptDecoder Initialization**: `model-jantung.glb` requires `EXT_meshopt_compression`. Standard Three.js `GLTFLoader` will throw an error if `MeshoptDecoder` is not attached via `loader.setMeshoptDecoder(MeshoptDecoder)`.

The layout recommendations provide a clean single-viewport fit for both mobile (with 3D hidden, focusing on compact project card and CTA) and desktop ($\ge 1024\text{px}$). If mobile 3D is re-enabled, a scaled-down canvas (`w-[280px] h-[300px]`) must be used.
